Audio for the sample game
=========================

Every file in this folder was generated by synthesis (square and triangle
waves plus noise, 8-bit style) specifically for this project: none of it comes
from a third-party pack, and it can be used freely.

  sfx/jump.wav        player jump
  sfx/land.wav        landing
  sfx/hurt.wav        hit (still alive)
  sfx/die.wav         death
  sfx/collect.wav     fruit collected
  sfx/checkpoint.wav  flag activated
  sfx/win.wav         goal reached
  sfx/bounce.wav      trampoline
  sfx/crumble.wav     falling platform, when stepped on
  music/platformer_theme.wav   8-bar loop (12.8 s) that repeats seamlessly

16-bit mono WAV at 44.1 kHz. To replace them with others (for example the CC0
audio from the Ninja Adventure pack): copy the files into assets/audio/ and
pick them in the Inspector (SoundEffects on each prefab, Music on the "Music"
entity). The engine reads WAV, OGG Vorbis and Opus.
